# WebMCP change history

This timeline follows the upstream `main` history through commit [`50c4b7fd6c4402731271649bc544b662b061ed44`](https://github.com/webmachinelearning/webmcp/commit/50c4b7fd6c4402731271649bc544b662b061ed44), dated 4 September 2026. Dates below are committer dates from the upstream git history; they are not necessarily author or merge dates. Entries identify merged commits; an issue or PR link is called out separately when it is still an open design pointer. This is a history of the proposal, not a claim that every historical API remains current.

## Origins and initial proposal (August 2025–January 2026)

* **5 August 2025 — repository and first explainers.** The project began with boilerplate (`e9a5477`) and an initial explainer (`71b3025`). A second initial explainer was added on 6 August (`4ab8c65`), then the Script Tools API and WebMC explainers were merged on 7 August (`9de1d71`). The project was renamed and the README updated on 8 August (`6748764`, [`d6433c7`](https://github.com/webmachinelearning/webmcp/commit/d6433c72ab3f012e9d9194708f812741d4311194)); the rename landed through merged PR [#4](https://github.com/webmachinelearning/webmcp/pull/4).
* **13 August 2025 — first consolidation.** Feedback was addressed in [`446069b`](https://github.com/webmachinelearning/webmcp/commit/446069b6b666a60affb6cf1dfa498d3f2191cdce), then the explainer merge landed through PR [#3](https://github.com/webmachinelearning/webmcp/pull/3). The README became the primary project-facing explanation on 22–25 August (`be28b36`, `24bcd85`, merged PR [#14](https://github.com/webmachinelearning/webmcp/pull/14)).
* **4 September–9 October 2025 — service-worker and MCP context.** A service-worker explainer was introduced by [`2ea03e8`](https://github.com/webmachinelearning/webmcp/commit/2ea03e8d1756471c3274609eabb1c7b5ee3481c2), with merged PR [#19](https://github.com/webmachinelearning/webmcp/pull/19). The MCP intersection explainer landed 9 October through [`082be8b`](https://github.com/webmachinelearning/webmcp/commit/082be8b77ca0c69c98e2b5f6e7bc4acd127a8002) and PR [#36](https://github.com/webmachinelearning/webmcp/pull/36). API syntax was then aligned with resolutions in [`2aee7d0`](https://github.com/webmachinelearning/webmcp/commit/2aee7d010d88da1ecfbd4c0d717ee46d6a05d850) and merged PR [#37](https://github.com/webmachinelearning/webmcp/pull/37).
* **November–December 2025 — elicitation and security groundwork.** The explainer was updated through PR [#46](https://github.com/webmachinelearning/webmcp/pull/46); an elicitation API appeared in [`38bdb67`](https://github.com/webmachinelearning/webmcp/commit/38bdb673547ce3d7688f7da6981a49bca13f7363), but it is not part of the current `ModelContext` IDL. Security text evolved from “input injection” to attack-target analysis (`c389e90`, `ae88545`), then the attack-target section was restored and expanded in [`b55e5ba`](https://github.com/webmachinelearning/webmcp/commit/b55e5ba55bea7560591cd5d91af0a2d771e17a10) and [`c4af04c`](https://github.com/webmachinelearning/webmcp/commit/c4af04c3e89867900e45d19c4cee7f144d2ed12d), merged through PR [#59](https://github.com/webmachinelearning/webmcp/pull/59). These are historical security iterations; consult the current rendered section rather than assuming all early terminology survives.
* **26 January 2026 — initial Bikeshed specification.** [`92080f3`](https://github.com/webmachinelearning/webmcp/commit/92080f3386dc4fd58410601ea7a244d7b84b806c) added the initial spec draft and CI/CD setup. Initial WebIDL, annotations, and definitions were added 4–12 February (`2b11f27`, [`ba7a885`](https://github.com/webmachinelearning/webmcp/commit/ba7a8853aa10fab8360e21c2ca9f7ef583c9e901), [`349abab`](https://github.com/webmachinelearning/webmcp/commit/349ababffac5c0975516b5a1e1a6f7b0b006611b), `971aa24`).

## Normative API formation (February–June 2026)

* **19 February — initial model-context setup.** The work initialized a navigator model context (`41dd829`, `3e1d68b`).
* **2–5 March — registration core and removals.** [`643b92c`](https://github.com/webmachinelearning/webmcp/commit/643b92c3e5fb5be34621ae4fa2d32f874071e697) completed basic `registerTool()`/`unregisterTool()` infrastructure. `provideContext()` and `clearContext()` were subsequently removed in [`fe84c67`](https://github.com/webmachinelearning/webmcp/commit/fe84c677c381f1f526af6e015f25d34684b0b45c). The declarative forms proposal was added 9 March in [`ebfccbe`](https://github.com/webmachinelearning/webmcp/commit/ebfccbec9fb48feb68d3d037730012e8b51fe079), associated with issue [#22](https://github.com/webmachinelearning/webmcp/issues/22).
* **26 March–29 May — lifecycle, metadata, observation, and security.** Registration gained an optional `AbortSignal` in [`6708e33`](https://github.com/webmachinelearning/webmcp/commit/6708e3399871458c07ed4cddc04057dec2549955), tool names/title requirements were codified in [`1380910`](https://github.com/webmachinelearning/webmcp/commit/138091043124a5662333b5863b482fe969de1718), and page observation infrastructure plus `untrustedContentHint` followed (`e1ddba1`, `a99ffd2`). Permission-policy integration and `toolchange` processing landed in [`a816d2e`](https://github.com/webmachinelearning/webmcp/commit/a816d2e91d762adb9f3a07e1d5ce81f462ccd45a) (merged PR [#179](https://github.com/webmachinelearning/webmcp/pull/179)). Security/privacy considerations were ported into the spec by [`7ff82c1`](https://github.com/webmachinelearning/webmcp/commit/7ff82c1899349d254f521b62ab85544499fa072b), while mitigations were repeatedly revised (`93b31ab`, `ab7630d`).
* **27 May — document-scoped context.** The design moved to a `Document`-associated `modelContext` in [`c7b5c70`](https://github.com/webmachinelearning/webmcp/commit/c7b5c7023f6e6a1c7a2495946136eb19b3109ae6), merged PR [#184](https://github.com/webmachinelearning/webmcp/pull/184). This is why current examples use `document.modelContext`, not the earlier navigator form.
* **8–17 June — promise and cancellation semantics.** `registerTool()` was changed to return a promise in [`ec37ec4`](https://github.com/webmachinelearning/webmcp/commit/ec37ec4878e08a166f1460ac40b1ca4ab8096d14). The security questionnaire was added through merged PR [#195](https://github.com/webmachinelearning/webmcp/pull/195), and [`bc93f03`](https://github.com/webmachinelearning/webmcp/commit/bc93f030aa24d14eb24d5cb6dfc373c0b4aae0d8) made an already-aborted registration signal reject. The historical `ModelContextClient` was removed in [`067a1c9`](https://github.com/webmachinelearning/webmcp/commit/067a1c90b5364b02742ef6ce40e5cf5a6497b445).

## Discovery and execution APIs (July–August 2026)

* **20–28 July — tools become inspectable and executable in-page.** Visibility was clarified in [`1aece7c`](https://github.com/webmachinelearning/webmcp/commit/1aece7c5258dbd17d4e50a7753132790c8d7925b), annotations were separated in [`d29b8d7`](https://github.com/webmachinelearning/webmcp/commit/d29b8d7d8d134749aca49bfd18222fe5d8671553), and `getTools()` was specified in [`5801678`](https://github.com/webmachinelearning/webmcp/commit/58016782fa379c25bc9584433f29127a9855647b). These commits establish the current in-page discovery shape.
* **12–19 August — `executeTool()` and robust races.** `executeTool()` was specified in [`f303c45`](https://github.com/webmachinelearning/webmcp/commit/f303c458754a5dbdacf47c72dab7f177bef884db). `inputSchema` changed from a DOMString to an object in [`384e110`](https://github.com/webmachinelearning/webmcp/commit/384e11010a690c3605e9556f63732e5ea19165b7), and `executeTool()` began accepting an object in [`a724ab1`](https://github.com/webmachinelearning/webmcp/commit/a724ab1ddb7ea770f425934de4d9424e85599940). Parameter mismatches and registration/notification/observation bugs were corrected in [`9c7ce3e`](https://github.com/webmachinelearning/webmcp/commit/9c7ce3e35e9124e46c4f21fc12dce38b9a5753b9) and [`3aafb9c`](https://github.com/webmachinelearning/webmcp/commit/3aafb9cdde39ecdc7e5b7b9cbdcfe7722a6afcde). `AbortSignal` execution integration landed in [`83e893a`](https://github.com/webmachinelearning/webmcp/commit/83e893ac3eaa8d72610062933c33a79494bf4fb5), and unregistration was made non-destructive to in-flight calls in [`fca7462`](https://github.com/webmachinelearning/webmcp/commit/fca7462d703c628f4cf110ddadd51e8e5b52a579).
* **12 August–4 September — implementation and author guidance.** Implementation status was introduced by [`c3a63b2`](https://github.com/webmachinelearning/webmcp/commit/c3a63b22341b439ed66cd7d3d71367abccdb0554); ChatGPT Desktop support was recorded in [`2ac94f5`](https://github.com/webmachinelearning/webmcp/commit/2ac94f537214c4b84f55eb03b644198be44289f0), and agent support was added on 2 September in [`55fb7ee`](https://github.com/webmachinelearning/webmcp/commit/55fb7ee2289679fbbbf3b1f8fc2f92daf96e6ba9). The consequential annotation landed 3 September in [`7b3f50f`](https://github.com/webmachinelearning/webmcp/commit/7b3f50f31848b529e69bedbbdf8da0edccba055f), resolving the earlier discussion tracked by [issue #176](https://github.com/webmachinelearning/webmcp/issues/176). On 4 September, the repository corrected declarative JSON-LD media type (`3204721`), refreshed stale examples (`16861c6`), added local Chromium development flag guidance (`2092f25`), added best practices (`f389d31`), refactored diagrams (`5f0c737`), and explicitly documented headless use cases (`50c4b7f`, merged PR [#296](https://github.com/webmachinelearning/webmcp/pull/296)).
