# Requirements Archive: v1.0 MVP

**Archived:** 2026-02-11
**Status:** SHIPPED

This archive captures v1 requirement outcomes at ship time.

## Final Requirement Outcomes

### Runtime Foundation

- [x] **RUNT-01**: Operator can install dependencies and complete a successful local build from this repository.
- [x] **RUNT-02**: Operator can start the MCP server locally and see the pre-scraping toolset registered.

### Core Automation Tools

- [x] **AUTO-01**: User can navigate to a URL via `browser_navigate`.
- [x] **AUTO-02**: User can wait for time/text/text disappearance via `browser_wait_for`.
- [x] **AUTO-03**: User can click a target element via `browser_click`.
- [x] **AUTO-04**: User can type text into a target element via `browser_type`.
- [x] **AUTO-05**: User can select one or more dropdown values via `browser_select_option`.
- [x] **AUTO-06**: User can issue keyboard input via `browser_press_key`.
- [x] **AUTO-07**: User can close the active browser page/session via `browser_close`.

### Discovery and Inspection Tools

- [x] **DISC-01**: User can capture a structured accessibility snapshot for selector reasoning via `browser_snapshot`.
- [x] **DISC-02**: User can evaluate JavaScript for controlled page/element inspection via `browser_evaluate`.
- [x] **DISC-03**: User can inspect captured network activity via `browser_network_requests`.
- [x] **DISC-04**: User can inspect browser console output via `browser_console_messages`.
- [x] **DISC-05**: User can capture page screenshots for visual verification via `browser_screenshot`.

### Pre-Scraping Workflow

- [x] **FLOW-01**: User can run an LLM-guided discovery pass that outputs selectors suitable for procedural extraction.

### Scope Adjustment During v1

- **FLOW-02 (dropped):** Selector handoff/export artifact was explicitly removed from v1 scope as YAGNI and scrubbed from active requirements/roadmap docs.
