## Objective

Complete the message routing infrastructure so that ALL MCP tools can successfully communicate with the browser extension. The extension currently only routes 3 message types, causing 18 tool types to fail with "Unknown message type" errors.

**Purpose:** This is a critical blocking gap—Phase 2's interactive tools were "implemented" in MCP but can't actually route messages to extension handlers. This plan completes the routing layer.

**Output:** A fully functional message routing system supporting all 21 message types across navigation, interaction, waiting, capture, evaluation, session, and state categories.

---

## Context

### The Gap

Live testing revealed that `extension/background.js` only routes 3 message types in the `directMessageTypes` map (lines 403-407):

```javascript
const directMessageTypes = {
  'browser_get_network_requests': 'getNetworkRequests',
  'browser_get_console_messages': 'getConsoleMessages',
  'removed selector export tool': 'removed selector export'
};
```

But ALL other MCP tools send direct message types that fall through to "Unknown message type" error:
- Navigation: `browser_navigate`, `browser_go_back`, `browser_go_forward`
- Interaction: `browser_click`, `browser_type`, `browser_select_option`, `browser_drag`, `browser_hover`, `browser_press_key`
- Waiting: `browser_wait`, `browser_wait_for`
- Capture: `browser_screenshot`, `browser_snapshot`, `browser_get_console_logs`
- Evaluation: `browser_evaluate`
- Session: `browser_close`
- State: `getUrl`, `getTitle`

### Evidence

Browser console logs show these messages reaching the extension but getting rejected:
```
[Browser MCP] Received command from MCP: { id: "...", type: "browser_navigate", payload: {...} }
[Browser MCP] Received command from MCP: { id: "...", type: "getUrl" }
```

### Current State

**Existing handlers (12 commands):**
- navigate, click, type, evaluate, screenshot, snapshot, select_option, wait, getTabs, getNetworkRequests, getConsoleMessages, removed selector export

**Missing handler functions (9 commands):**
- go_back, go_forward, press_key, wait_for, drag, hover, close, getUrl, getTitle, getConsoleLogs

   - Return { success: true }

   - Call resolveTargetTabId(params) to get target tab
   - Send message to content script: { type: 'executeCommand', command: 'press_key', params: { key } }

4. handleWaitFor(params):
   - Call resolveTargetTabId(params) to get target tab
   - Send message to content script: { type: 'executeCommand', command: 'wait_for', params: { mode, value, timeout } }
   - Return content script response

   - Call resolveTargetTabId(params) to get target tab
   - Send message to content script: { type: 'executeCommand', command: 'drag', params: { startElement, endElement } }
   - Return content script response

6. handleHover(params):
   - Call resolveTargetTabId(params) to get target tab
   - Send message to content script: { type: 'executeCommand', command: 'hover', params: { element } }
   - Return content script response

7. handleClose(params):
   - Call resolveTargetTabId(params) to get target tab
   - Call stopWebSocketServer('user_close')

## Verification

### Integration Tests

1. **Navigate flow:**
   - browser_navigate creates session tab and loads URL
   - browser_go_back navigates back in history
   - browser_go_forward navigates forward in history

2. **Interaction flow:**
   - browser_click finds and clicks element
   - browser_type enters text into input
   - browser_select_option selects dropdown option
   - browser_press_key simulates key press
   - browser_drag drags element
   - browser_hover triggers hover state

3. **Wait flow:**
   - browser_wait pauses for time
   - browser_wait_for waits for text to appear/disappear

4. **Capture flow:**
   - browser_screenshot returns PNG data
   - browser_snapshot returns accessibility tree
   - browser_get_console_logs returns captured logs

5. **State flow:**
   - getUrl returns current URL
   - getTitle returns page title

6. **Session flow:**
   - browser_close terminates session

### Error Handling

- All handlers use resolveTargetTabId() which throws SESSION_NOT_INITIALIZED or SESSION_TAB_CLOSED errors
- Content script errors propagate back through promise chain
- Unknown commands return COMMAND_FAILED with ErrorCodes
