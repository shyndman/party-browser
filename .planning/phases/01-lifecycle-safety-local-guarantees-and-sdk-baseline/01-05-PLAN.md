  <action>
    Replace the killProcessOnPort function with a graceful termination strategy:
    
    For Unix (Linux/macOS):
    1. First try SIGTERM (-15): lsof -ti:${port} | xargs kill -15 2>/dev/null || true
    2. Wait 1 second
    3. Check if port is still in use
    4. If still in use, try SIGKILL (-9) as fallback
    5. Suppress errors - no process on port is expected/normal
    
    For Windows:
    1. Use taskkill /T (terminate tree) without /F first
    2. Wait and check if port is free
    3. Only use /F (force) if graceful termination fails
    4. Suppress output with stdio: 'pipe' to avoid console spam
    
    Key changes from current:
    - Use SIGTERM (-15) instead of SIGKILL (-9) as first attempt
    - Add delay between graceful and force kill
    - Suppress error logging (no process on port is normal)
    - Use stdio: 'pipe' on Windows to suppress taskkill output
    
    The function should be idempotent - running it when no process uses the port should succeed silently.
  </action>
