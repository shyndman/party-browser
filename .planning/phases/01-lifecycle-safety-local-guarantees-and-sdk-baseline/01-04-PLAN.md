  <name>Task 2: Create MCP runtime smoke test script</name>
  <files>scripts/smoke-test-mcp.ts</files>
  <action>
    Create a smoke test script that validates STACK-01 runtime compatibility:
    
    1. Spawn the MCP server process via stdio transport
    2. Send initialize request with protocolVersion "2024-11-05"
    3. Verify server responds with capabilities including tools and resources
    4. Send tools/list request
    5. Verify response contains expected browser tools:
       - browser_navigate
       - browser_click
       - browser_type
       - browser_snapshot
       - browser_screenshot
    6. Send a sample tool call to browser_navigate with test URL
    7. Verify the server accepts the call (may return error if no extension, but must not crash)
    8. Send graceful shutdown request
    9. Verify process exits cleanly
    
    Use MCP SDK client or raw JSON-RPC over stdio.
    Handle timeouts (5s per operation) to prevent hanging.
    
    This validates:
    - SDK 1.26.x compatibility with existing tool schemas
    - Server starts and accepts MCP connections
    - Tool registration works correctly
    - Protocol-level compatibility maintained
  </action>
