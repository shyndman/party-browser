  <files>src/ws.ts</files>
  <action>
    Modify createWebSocketServer to enhance the close behavior:
    
    1. After creating WebSocketServer, store original close with bind
    2. Override wss.close to:
       - Iterate through wss.clients
       - For each client with readyState === WebSocket.OPEN, call ws.close(1001, "Server shutting down")
       - 1001 is the standard "Going Away" close code
       - Then call originalClose(callback)
    
    This ensures browser extension receives proper disconnect notification before the server terminates.
    
    Pattern:
    ```typescript
    const originalClose = wss.close.bind(wss);
    wss.close = (callback?: (err?: Error) => void) => {
      wss.clients.forEach((ws: WebSocket) => {
        if (ws.readyState === WebSocket.OPEN) {
          ws.close(1001, "Server shutting down");
        }
      });
      return originalClose(callback);
    };
    ```
  </action>
  <verify>grep -q "1001" src/ws.ts && grep -q "Server shutting down" src/ws.ts</verify>
  <done>ws.ts notifies clients with close code 1001 before closing server</done>
