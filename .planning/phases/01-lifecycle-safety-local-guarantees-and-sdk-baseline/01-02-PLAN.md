  <name>Task 1: Fix recursive close bug in server.ts</name>
  <files>src/server.ts</files>
  <action>
    Fix the infinite recursion bug at lines 85-89 in src/server.ts.
    
    Current buggy code:
    ```typescript
    server.close = async () => {
      await server.close();  // Recursive - calls the NEW server.close!
      await wss.close();
      await context.close();
    };
    ```
    
    Fixed code using bind pattern:
    ```typescript
    const originalClose = server.close.bind(server);
    server.close = async () => {
      await originalClose();  // Calls Protocol.close() → transport.close()
      await wss.close();
      await context.close();
    };
    ```
    
    This stores the original Protocol.close method before overriding it, preventing the recursive loop.
  </action>
  <verify>grep -n "originalClose = server.close.bind" src/server.ts</verify>
  <done>server.ts uses bind pattern to store original close before override</done>
</task>

          ws.close(1001, "Server shutting down");
        }
      });
      return originalClose(callback);
    };
