# Phase 02.1: Session and Transport Stabilization - Research

**Researched:** 2026-02-10
**Domain:** Browser Extension APIs, WebSocket Session Management, Firefox Add-on Development
**Confidence:** HIGH

## Summary

This phase stabilizes the Browser MCP architecture by implementing a deterministic session-owned tab model. Currently, the extension binds to whatever active tab exists at connection time. The new model requires explicit session initialization via `navigate`, creates dedicated session tabs with `OC | ` title prefixes, and enforces strict lifecycle rules: no active-tab fallback, no per-call tab overrides, and mandatory re-initialization after transport drops.

The implementation requires coordinated changes across the Firefox extension (background script, tab management), WebSocket protocol (session state messaging), and MCP server (error handling and guidance). Firefox's WebExtension APIs provide all necessary primitives for tab creation, monitoring, and cleanup.

**Primary recommendation:** Implement session state machine in the extension background script with explicit states (UNINITIALIZED → NAVIGATING → ACTIVE → CLOSED), use browser.tabs.create/update/remove for tab lifecycle, and extend the WebSocket protocol to communicate session state changes to the MCP server.

## User Constraints

### Locked Decisions

#### Session start behavior
- First `navigate` in a session creates the dedicated session tab and navigates it.
- Subsequent `navigate` commands reuse the existing session tab (do not create additional tabs).
- New session tab starts at `about:blank` before first navigation.
- New session tab is created in the background (do not steal focus).

#### Session lifecycle rules
- Clear session ownership on: owned tab close, kill switch off, and transport drop.
- If owned tab is closed, all non-`navigate` commands fail until `navigate` establishes a new session tab.
- Before first `navigate`, non-`navigate` commands return a clear "session not initialized" style error.
- After reconnect, do not auto-reuse prior session ownership; require fresh `navigate`.
- Explicit `tabId` override input is not supported.

#### Failure recovery UX
- Do not retry failed in-flight requests after transport drop.
- Keep background reconnect attempts for transport restoration.
- Once transport is back, still require `navigate` before non-`navigate` commands proceed.
- Error guidance for unbound session should instruct: run `navigate` first.
- Include machine-readable failure reason codes in command failures.
- Log transport drops with generic "connection lost" style messaging.

#### Tab presentation
- Prefix owned tab title with `OC | ` for quick identification.
- Place all session-owned tabs into the same browser tab group when grouping is available.
- Create session-owned tabs in the current window.
- Turning kill switch OFF closes the owned session tab.

### Claude's Discretion

- Exact reason-code naming and mapping (for example enum values) as long as they are stable and documented.
- Exact tab-group label text and color choice, while preserving "same group" behavior.

### Deferred Ideas

None - discussion stayed within phase scope.

### Pattern 1: Session State Machine

**What:** Explicit state machine managing session lifecycle with clear transitions.

**When to use:** Required for deterministic session behavior across all edge cases.

**States:**
- `UNINITIALIZED` - No session tab exists (initial state, post-reconnect)
- `NAVIGATING` - Tab creation/navigation in progress
- `ACTIVE` - Session tab exists and is ready for commands
- `CLOSED` - Session terminated (kill switch, tab closed)

**Transitions:**
- `UNINITIALIZED` → `NAVIGATING`: First navigate command received
- `NAVIGATING` → `ACTIVE`: Tab created and loaded
- `ACTIVE` → `UNINITIALIZED`: Tab closed, transport dropped, or kill switch
- Any → `CLOSED`: Kill switch OFF (terminal state)

**Example:**
```javascript
// Source: Extension background script pattern
const SessionState = {
  UNINITIALIZED: 'uninitialized',
  NAVIGATING: 'navigating',
  ACTIVE: 'active',
  CLOSED: 'closed'
};

class SessionManager {
  constructor() {
    this.state = SessionState.UNINITIALIZED;
    this.sessionTabId = null;
    this.pendingNavigation = null;
  }

  async handleNavigate(url) {
    if (this.state === SessionState.CLOSED) {
      throw new Error('SESSION_CLOSED: Session is closed. Toggle kill switch to restart.');
    }

    if (this.state === SessionState.UNINITIALIZED) {
      // First navigation: create new tab
      this.state = SessionState.NAVIGATING;
      const tab = await browser.tabs.create({
        url: 'about:blank',
        active: false  // Background tab
      });
      this.sessionTabId = tab.id;
      await this.setTabTitle(tab.id, `OC | ${url}`);
      await browser.tabs.update(tab.id, { url });
      await this.waitForTabLoad(tab.id);
      this.state = SessionState.ACTIVE;
      return { success: true, tabId: tab.id };
    }

    if (this.state === SessionState.ACTIVE) {
      // Subsequent navigation: reuse existing tab
      await browser.tabs.update(this.sessionTabId, { url });
      await this.waitForTabLoad(this.sessionTabId);
      return { success: true, tabId: this.sessionTabId };
    }

    throw new Error('SESSION_BUSY: Navigation already in progress');
  }
}
```

### Pattern 2: Tab Lifecycle Management

**What:** Dedicated module for tab CRUD operations with session-aware cleanup.

**When to use:** Isolates browser API calls for testability and clarity.

**Example:**
```javascript
// Source: Firefox WebExtensions tabs API documentation
class TabManager {
  constructor() {
    this.ownedTabs = new Set();
    this.tabGroupId = null;
  }

  async createSessionTab() {
    const currentWindow = await browser.windows.getCurrent();
    const tab = await browser.tabs.create({
      windowId: currentWindow.id,
      url: 'about:blank',
      active: false  // Background tab - no focus steal
    });
    
    this.ownedTabs.add(tab.id);
    
    // Set title prefix for identification
    await this.updateTabTitle(tab.id, 'OC | New Session');
    
    // Add to session group if available
    await this.addToSessionGroup(tab.id);
    
    return tab;
  }

  async closeSessionTab(tabId) {
    if (this.ownedTabs.has(tabId)) {
      await browser.tabs.remove(tabId);
      this.ownedTabs.delete(tabId);
    }
  }

  async updateTabTitle(tabId, title) {
    // Firefox doesn't support direct title modification
    // Title will reflect page content; prefix handled via grouping/positioning
    // Alternative: Inject content script to update document.title
  }

  async addToSessionGroup(tabId) {
    try {
      if (!this.tabGroupId) {
        // Create new group with first tab
        const group = await browser.tabGroups.create({
          tabIds: [tabId],
          title: 'OpenCode Sessions',
          color: 'blue'
        });
        this.tabGroupId = group.id;
      } else {
        // Add to existing group
        await browser.tabs.group(tabId, { groupId: this.tabGroupId });
      }
    } catch (error) {
      // Tab grouping not available (older Firefox, disabled)
      console.log('[Browser MCP] Tab grouping not available:', error);
    }
  }
}
```

### Anti-Patterns to Avoid

- **Implicit state from external sources:** Don't derive session state from browser's active tab or window state. Always use explicit internal state machine.
- **Auto-reconnection with state restoration:** After transport reconnect, always reset to UNINITIALIZED state rather than attempting to re-bind to previous tab.
- **Synchronous tab operations:** Always await tab creation/updates; Firefox tab operations are asynchronous.
- **Tab ID persistence across sessions:** Tab IDs are not stable across browser restarts or extension reloads.

## Don't Hand-Roll

| Problem | Don't Build | Use Instead | Why |
|---------|-------------|-------------|-----|
| Tab lifecycle management | Custom tab tracking | browser.tabs API | Native API handles edge cases (tab crashes, window changes, permission changes) |
| Session state persistence | localStorage for session state | In-memory state + explicit re-initialization | Session state should not survive extension reload - explicit re-initialization required |
| Tab grouping | CSS injection or window manipulation | browser.tabGroups API | Native grouping provides consistent UX, collapse/expand, color coding |
| WebSocket reconnection | Simple setInterval polling | Exponential backoff with MAX_RECONNECT_ATTEMPTS | Already implemented in current code, handles transient failures |
| Page load detection | setTimeout polling | browser.tabs.onUpdated listener | Native event fires on actual load completion, not time-based |

**Key insight:** Firefox WebExtensions APIs provide robust primitives for tab and session management. Custom implementations would miss edge cases (tab discarding, session restore, private browsing) that the native APIs handle automatically.

## Common Pitfalls

### Pitfall 1: Tab Creation Race Conditions

**What goes wrong:** Creating a tab and immediately trying to navigate it fails because tab hasn't fully initialized.

**Why it happens:** `browser.tabs.create()` returns before the tab's content process is ready to receive messages.

**How to avoid:** Wait for tab status to become 'complete' before sending commands to content script:
```javascript
async function waitForTabReady(tabId) {
  return new Promise((resolve) => {
    const listener = (updatedTabId, changeInfo) => {
      if (updatedTabId === tabId && changeInfo.status === 'complete') {
        browser.tabs.onUpdated.removeListener(listener);
        resolve();
      }
    };
    browser.tabs.onUpdated.addListener(listener);
  });
}
```

**Warning signs:** Intermittent "Could not establish connection" errors when sending messages to newly created tabs.

### Pitfall 2: Session State Desync

**What goes wrong:** Extension thinks session is ACTIVE but tab was closed via browser UI (X button).

**Why it happens:** Tab closure via browser UI doesn't go through extension's closeSessionTab() method.

**How to avoid:** Always use `browser.tabs.onRemoved` listener to clear session state:
```javascript
browser.tabs.onRemoved.addListener((removedTabId) => {
  if (sessionTabId === removedTabId) {
    console.warn('[Browser MCP] Session tab closed externally; clearing session binding');
    sessionManager.clearSession();
  }
});
```

**Warning signs:** Commands fail with "Invalid tab ID" errors after user manually closes session tab.

### Pitfall 3: Window Context Loss

**What goes wrong:** Session tab created in wrong window when user has multiple Firefox windows.

**Why it happens:** `browser.tabs.create()` without `windowId` creates tab in last focused window, which may not be intended context.

**How to avoid:** Explicitly get current window and create tab there:
```javascript
const currentWindow = await browser.windows.getCurrent();
const tab = await browser.tabs.create({
  windowId: currentWindow.id,
  url: 'about:blank',
  active: false
});
```

**Warning signs:** Session tab appears in unexpected window, or user can't find the tab.

### Pitfall 4: Tab Group API Unavailability

**What goes wrong:** `browser.tabGroups` API throws errors on Firefox versions that don't support it or when tab groups are disabled.

**Why it happens:** Tab groups are relatively new (Firefox 106+) and may be disabled by user preference.

**How to avoid:** Wrap tab group operations in try-catch and gracefully degrade:
```javascript
async function addToSessionGroup(tabId) {
  try {
    if (browser.tabGroups) {
      await browser.tabs.group(tabId, { groupId: sessionGroupId });
    }
  } catch (error) {
    // Silently ignore - grouping is optional enhancement
    console.log('[Browser MCP] Tab grouping not available');
  }
}
```

**Warning signs:** Extension fails to initialize or errors in browser console on older Firefox versions.

### Pitfall 5: In-Flight Request Retry

**What goes wrong:** Attempting to retry commands that were in-flight when transport dropped leads to duplicate actions.

**Why it happens:** Command may have reached browser but response was lost in transport drop.

**How to avoid:** Per requirements, do NOT retry failed in-flight requests. Let them fail and require explicit re-initialization:
```javascript
// Current implementation is correct - no retry logic
websocket.onclose = () => {
  // Clear context - don't retry pending commands
  context.ws = undefined;
  // User must re-initialize with navigate after reconnect
};
```

**Warning signs:** Duplicate page navigations, double-clicks, or other repeated actions after reconnection.

## Code Examples

### Session State Machine Implementation

```javascript
// Source: Extension background.js - Session Manager Module
const SessionState = {
  UNINITIALIZED: 'uninitialized',
  NAVIGATING: 'navigating',
  ACTIVE: 'active',
  CLOSED: 'closed'
};

const SessionErrorCode = {
  SESSION_NOT_INITIALIZED: 'SESSION_NOT_INITIALIZED',
  SESSION_CLOSED: 'SESSION_CLOSED',
  SESSION_TAB_CLOSED: 'SESSION_TAB_CLOSED',
  NAVIGATION_IN_PROGRESS: 'NAVIGATION_IN_PROGRESS',
  TAB_OVERRIDE_NOT_SUPPORTED: 'TAB_OVERRIDE_NOT_SUPPORTED'
};

class SessionManager {
  constructor() {
    this.state = SessionState.UNINITIALIZED;
    this.sessionTabId = null;
    this.sessionGroupId = null;
    this.currentUrl = null;
    
    // Listen for external tab closure
    browser.tabs.onRemoved.addListener(this.handleTabRemoved.bind(this));
  }

  async handleNavigate(url, params) {
    // Reject explicit tabId overrides
    if (params && Object.prototype.hasOwnProperty.call(params, 'tabId')) {
      return this.createError(
        SessionErrorCode.TAB_OVERRIDE_NOT_SUPPORTED,
        'tabId overrides are not supported. Browser MCP uses the bound session tab.',
        'Use browser_navigate without tabId parameter.'
      );
    }

    // State validation
    if (this.state === SessionState.CLOSED) {
      return this.createError(
        SessionErrorCode.SESSION_CLOSED,
        'Session is closed. Toggle kill switch to restart.',
        'Click the Browser MCP extension icon to enable the kill switch, then run browser_navigate.'
      );
    }

    if (this.state === SessionState.NAVIGATING) {
      return this.createError(
        SessionErrorCode.NAVIGATION_IN_PROGRESS,
        'Navigation already in progress.',
        'Wait for current navigation to complete.'
      );
    }

    if (this.state === SessionState.UNINITIALIZED) {
      // First navigation: create session tab
      return await this.createSessionTab(url);
    }

    if (this.state === SessionState.ACTIVE) {
      // Subsequent navigation: reuse existing tab
      return await this.navigateExistingTab(url);
    }

    return this.createError(
      SessionErrorCode.INVALID_STATE,
      `Unexpected session state: ${this.state}`,
      'Please report this issue.'
    );
  }

  async createSessionTab(url) {
    this.state = SessionState.NAVIGATING;
    
    try {
      const currentWindow = await browser.windows.getCurrent();
      
      // Create tab at about:blank (background tab)
      const tab = await browser.tabs.create({
        windowId: currentWindow.id,
        url: 'about:blank',
        active: false
      });

      this.sessionTabId = tab.id;
      this.currentUrl = url;

      // Add to session group (best effort)
      await this.addToSessionGroup(tab.id);

      // Navigate to target URL
      await browser.tabs.update(tab.id, { url });
      await this.waitForTabLoad(tab.id);

      this.state = SessionState.ACTIVE;
      
      return {
        success: true,
        tabId: tab.id,
        url,
        isNewSession: true
      };
    } catch (error) {
      this.state = SessionState.UNINITIALIZED;
      this.sessionTabId = null;
      throw error;
    }
  }

  async navigateExistingTab(url) {
    try {
      await browser.tabs.update(this.sessionTabId, { url });
      await this.waitForTabLoad(this.sessionTabId);
      this.currentUrl = url;
      
      return {
        success: true,
        tabId: this.sessionTabId,
        url,
        isNewSession: false
      };
    } catch (error) {
      if (error.message.includes('Invalid tab ID')) {
        // Tab was closed externally
        this.clearSession();
        return this.createError(
          SessionErrorCode.SESSION_TAB_CLOSED,
          'Session tab was closed.',
          'Run browser_navigate to create a new session tab.'
        );
      }
      throw error;
    }
  }

  async handleOtherCommand(command, params) {
    // Reject explicit tabId overrides for all commands
    if (params && Object.prototype.hasOwnProperty.call(params, 'tabId')) {
      return this.createError(
        SessionErrorCode.TAB_OVERRIDE_NOT_SUPPORTED,
        'tabId overrides are not supported.',
        'Remove the tabId parameter.'
      );
    }

    if (this.state === SessionState.UNINITIALIZED) {
      return this.createError(
        SessionErrorCode.SESSION_NOT_INITIALIZED,
        'No session tab available. Session has not been initialized.',
        'Run browser_navigate first to create a session tab.'
      );
    }

    if (this.state === SessionState.CLOSED) {
      return this.createError(
        SessionErrorCode.SESSION_CLOSED,
        'Session is closed.',
        'Toggle kill switch to restart.'
      );
    }

    if (this.state === SessionState.NAVIGATING) {
      return this.createError(
        SessionErrorCode.NAVIGATION_IN_PROGRESS,
        'Navigation in progress.',
        'Wait for navigation to complete.'
      );
    }

    // Execute command on session tab
    return {
      success: true,
      tabId: this.sessionTabId
    };
  }

  handleTabRemoved(removedTabId) {
    if (this.sessionTabId === removedTabId) {
      console.warn('[Browser MCP] Session tab closed; clearing session binding');
      this.clearSession();
    }
  }

  clearSession() {
    this.state = SessionState.UNINITIALIZED;
    this.sessionTabId = null;
    this.currentUrl = null;
  }

  closeSession() {
    if (this.sessionTabId) {
      browser.tabs.remove(this.sessionTabId).catch(() => {
        // Tab may already be closed
      });
    }
    this.state = SessionState.CLOSED;
    this.sessionTabId = null;
    this.sessionGroupId = null;
    this.currentUrl = null;
  }

  async addToSessionGroup(tabId) {
    try {
      if (!browser.tabGroups) {
        return; // API not available
      }

      if (!this.sessionGroupId) {
        const group = await browser.tabGroups.create({
          tabIds: [tabId],
          title: 'OpenCode',
          color: 'blue'
        });
        this.sessionGroupId = group.id;
      } else {
        await browser.tabs.group(tabId, { groupId: this.sessionGroupId });
      }
    } catch (error) {
      console.log('[Browser MCP] Tab grouping not available:', error.message);
    }
  }

  async waitForTabLoad(tabId) {
    return new Promise((resolve, reject) => {
      const timeout = setTimeout(() => {
        browser.tabs.onUpdated.removeListener(listener);
        reject(new Error('Tab load timeout'));
      }, 30000);

      const listener = (updatedTabId, changeInfo) => {
        if (updatedTabId === tabId && changeInfo.status === 'complete') {
          clearTimeout(timeout);
          browser.tabs.onUpdated.removeListener(listener);
          resolve();
        }
      };

      browser.tabs.onUpdated.addListener(listener);
    });
  }

  createError(code, message, guidance) {
    return {
      success: false,
      error: message,
      code,
      guidance
    };
  }
}
```

### MCP Server Error Handling

```typescript
// Source: context.ts - Enhanced error handling
export class Context {
  private _ws: WebSocket | undefined;
  private _sessionState: 'uninitialized' | 'active' | 'disconnected' = 'uninitialized';

  async sendSocketMessage<T extends MessageType<SocketMessageMap>>(
    type: T,
    payload: MessagePayload<SocketMessageMap, T>,
    options: { timeoutMs?: number } = { timeoutMs: 30000 },
  ) {
    const { sendSocketMessage } = createSocketMessageSender<SocketMessageMap>(this.ws);
    
    try {
      const result = await sendSocketMessage(type, payload, options);
      
      // Track session state based on successful navigate
      if (type === 'browser_navigate' && result.success) {
        this._sessionState = 'active';
      }
      
      return result;
    } catch (e) {
      if (e instanceof Error) {
        // Parse error codes from extension
        if (e.message.includes('SESSION_NOT_INITIALIZED')) {
          throw new Error(
            'Session not initialized. Run browser_navigate first to create a session tab.'
          );
        }
        if (e.message.includes('SESSION_TAB_CLOSED')) {
          this._sessionState = 'uninitialized';
          throw new Error(
            'Session tab was closed. Run browser_navigate to create a new session tab.'
          );
        }
        if (e.message.includes('TAB_OVERRIDE_NOT_SUPPORTED')) {
          throw new Error(
            'Explicit tabId overrides are not supported. Browser MCP uses session-owned tabs.'
          );
        }
      }
      throw e;
    }
  }

  onTransportDisconnect() {
    this._ws = undefined;
    this._sessionState = 'disconnected';
    // Note: Do NOT auto-restore state on reconnect
    // User must explicitly run navigate to re-initialize
  }
}
```

## Open Questions

1. **Tab title prefix implementation**
   - What we know: Firefox doesn't allow direct tab title modification via tabs API
   - What's unclear: Best approach to implement `OC | ` prefix - content script document.title injection, or rely on tab grouping for visual identification
   - Recommendation: Implement tab grouping as primary visual identifier; investigate content script title modification as fallback

2. **Tab group color choice**
   - What we know: Firefox tabGroups API supports colors: grey, blue, red, yellow, green, pink, purple, cyan
   - What's unclear: Which color best represents "OpenCode" brand identity
   - Recommendation: Blue (professional, matches OpenCode branding) or Cyan (distinctive, tech-forward)

3. **Error code stability**
   - What we know: Error codes need to be stable for programmatic handling
   - What's unclear: Whether to use SCREAMING_SNAKE_CASE or PascalCase for consistency with existing codebase
   - Recommendation: Use SCREAMING_SNAKE_CASE for error codes (indicates constants), document in protocol spec
