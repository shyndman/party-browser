## Decisions Made

- **Navigate-time initialization:** Session tab created on first navigate, not on WebSocket connect. This ensures deterministic behavior and avoids race conditions with active tab detection.
- **Session persistence:** sessionTabId persists across reconnects but is NOT auto-restored. After disconnect, sessionTabId remains null until next navigate. This implements "do not auto-reuse prior session ownership after reconnect."
- **Error codes:** Used SCREAMING_SNAKE_CASE codes (SESSION_NOT_INITIALIZED, SESSION_TAB_CLOSED, EXPLICIT_TABID_NOT_SUPPORTED) for machine-readable error handling.
- **Graceful degradation:** Tab grouping uses try/catch since browser.tabGroups API may not be available in all Firefox versions.
