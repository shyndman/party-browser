<objective>
Implement deterministic session-owned tab model where the first navigate creates a session tab, subsequent commands target only that tab, and session lifecycle rules are strictly enforced. Remove all active-tab fallback behavior and reject per-call tabId overrides.

Purpose: Deterministic tab targeting is essential for reliable browser automation. The session must have clear ownership semantics: one tab per session, explicit initialization via navigate, and predictable cleanup.

Output: Background script with session state machine, navigate-based tab creation, comprehensive error codes.
</objective>

    Rewrite handleNavigate() to implement session tab lifecycle:
    1. If sessionTabId is null (no session tab exists):
       - Create new tab with url: 'about:blank', active: false (background)
       - Wait for tab load

       - Navigate the tab to target URL using browser.tabs.update(sessionTabId, { url })

       - Return success with tabId
    2. If sessionTabId exists (session already initialized):
       - Navigate existing tab to new URL using browser.tabs.update(sessionTabId, { url })
       - Wait for navigation complete
       - Return success with tabId
    3. Create helper function createSessionTab() that creates tab at about:blank in background
    
    This implements: "First navigate creates tab, second navigate reuses tab" and "New session tab starts at about:blank" and "New session tab is created in the background."
    
    Remove the current handleNavigate() implementation that uses resolveTargetTabId() and browser.tabs.update directly.
  </action>
