<objective>
Fix protocol unit alignment gaps in browser_get_console_logs and browser_wait_for tools.

Purpose: Three UAT-discovered issues: (1) getConsoleLogs expects array response but receives object with nested logs array, (2) wait_for mode=time treats seconds as milliseconds causing ~1000x faster completion, (3) wait_for mode=text timeout treated as milliseconds causing immediate failure. These are API contract violations between MCP server (seconds-based) and content script (milliseconds-based).

Output: Corrected response parsing in src/tools/custom.ts and unit conversion in extension/content-script.js waitForCondition function.
</objective>

    2. The issue: timeout comes in as seconds (e.g., 10), but Date.now() - startTime gives milliseconds.

       ```javascript

         const timeoutMs = timeoutSeconds * 1000;
         const startTime = Date.now();
       ```
