<objective>
Fix protocol unit alignment gaps in browser_get_console_logs and browser_wait_for tools, and perform application-wide timeout audit.

Purpose: Three UAT-discovered issues: (1) getConsoleLogs expects array response but receives object with nested logs array, (2) wait_for mode=time treats seconds as milliseconds causing ~1000x faster completion, (3) wait_for mode=text timeout treated as milliseconds causing immediate failure. Additionally, user requested comprehensive audit of all timeout/time-unit usages application-wide to identify and prevent similar issues. These are API contract violations between MCP server (seconds-based) and content script (milliseconds-based).

Output: 
- Corrected response parsing in src/tools/custom.ts
- Unit conversion fixes in extension/content-script.js handleWaitFor function
- Application-wide timeout audit documenting all timeout boundaries
- TIMEOUT CONTRACT documentation ensuring consistent units (seconds at API, milliseconds internally)
- Regression checks confirming no other timeout consumers are broken
</objective>
